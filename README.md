# BAZU Impact Stories

Modern, dark-theme landing page showcasing real success stories from BAZU video participants.

## Features

- 🎨 **Modern Dark Theme**: Clean black background with #ffed00 yellow accent
- 📊 **Animated Stats Counter**: Eye-catching numbers that animate on page load
- 📖 **8 Real Success Stories**: Detailed case studies with impact results
- ✨ **Smooth Animations**: Fade-in effects and hover interactions
- 📱 **Fully Responsive**: Perfect on all devices (mobile, tablet, desktop)
- ⚡ **Single HTML File**: Built with Tailwind CSS CDN for easy deployment

## Design

- **Colors**: Black (#000000) background, Yellow (#ffed00) accent
- **Typography**: Inter font family
- **Layout**: Grid-based responsive design
- **Animations**: Smooth scroll, fade-in on scroll, hover effects

## Tech Stack

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) (CDN)
- Vanilla JavaScript
- Google Fonts (Inter)

## Deployment

This project is ready for deployment on Vercel:

1. Connect your repository to Vercel
2. Deploy - no build configuration needed!
3. The `vercel.json` file handles routing automatically
